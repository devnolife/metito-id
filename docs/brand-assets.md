# Brand Assets

All METITO logo, icon and social-card files are **generated**, not hand-edited.
The single source of truth is the official letterhead artwork committed at
`DOKUMEN METITO/Kop Metito 2.png` (kingfisher mark + METITO wordmark).

## Regenerating

```bash
npm run brand:assets
```

This runs `scripts/generate-brand-assets.js`, which:

1. Knocks the flat near-white letterhead backdrop out to transparency using a
   flood fill seeded from the image border, so white *inside* the artwork (the
   bird's eye highlight, the letterform counters) is preserved.
2. Locates the gutter of empty columns separating the mark from the wordmark and
   derives the mark / wordmark / lockup bounding boxes from the alpha channel.
3. Writes every derivative listed below.

> Bounding boxes are computed in JS rather than with sharp's `trim()`: libvips
> flattens alpha before searching and returns a wrong box for this artwork.

## Generated files

| Path | Purpose |
| --- | --- |
| `app/favicon.ico` | Multi-size ICO (16/32/48). Next.js file convention — served at `/favicon.ico`. |
| `app/icon.png` | 512×512 PNG favicon, tight crop for small-size legibility. |
| `app/apple-icon.png` | 180×180 touch icon on a white plate (iOS renders transparency as black). |
| `app/opengraph-image.png` | 1200×630 social card, also used for the Twitter card. |
| `public/images/logo.png` | Square kingfisher mark. Consumed by every existing component. |
| `public/images/brand/logo-mark.png` | Same mark, canonical location. |
| `public/images/brand/logo-mark-{96,192,512}.png` | PWA icon sizes, referenced by `app/manifest.ts`. |
| `public/images/brand/logo-lockup.png` | Full horizontal lockup (mark + wordmark). |
| `public/images/brand/logo-wordmark.png` | Wordmark only. |
| `public/images/brand/letterhead-footer.png` | Official letterhead contact strip. |

`public/images/legacy/` holds the previous placeholder eagle logos, kept only for
reference — nothing in the app links to them.

## Metadata wiring

`app/icon.png`, `app/apple-icon.png`, `app/opengraph-image.png` and
`app/favicon.ico` are Next.js file conventions: the corresponding `<link>` and
`<meta>` tags are injected automatically, so they are **not** declared in the
`metadata` export of `app/layout.tsx`. The web app manifest is generated by
`app/manifest.ts`, which reads its copy from `lib/company-profile.ts`.
